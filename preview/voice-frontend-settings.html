运行方案

安装位置与环境

其下使用 venv\ 与 models\；不装进桌面 Program Files。
仅本机；手机远程连 Gateway :3101，不直接连 8765。
  • NVIDIA GPU / 驱动
  • Python 3.12（将创建工程 venv）
  • CUDA 版 PyTorch（安装向导写入 venv）
  • speech-to-speech[paraformer]（指定修订）
  • 模型权重（魔搭优先）
  • 方案 A：Qwen3-4B-Instruct-2507 ≈ 8 GB
等待安装…\n预计磁盘：方案 B 数 GB；含方案 A 约 15 GB 量级。\n模型不进入 git。

服务控制

对应工程脚本 scripts/start-local.ps1 -SpeechWorker。窗口标题「语音服务（请勿关闭）」。
