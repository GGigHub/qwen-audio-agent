高级 · 启动参数说明
启用 Smart Turn（去掉 --no_smart_turn）

默认关闭：需从 Hugging Face 拉 pipecat-ai/smart-turn-v3，国内易超时。关闭时打断仍靠 Silero VAD。

参数方案 B 示例说明
--sttparaformer听写；别名解析为 Paraformer-zh
--llm_backendchat-completionsB：HTTP 兼容接口；A：transformers 本地加载
--model_namedeepseek-chatB：云端对话名；A：本地 4B 目录
--responses_api_base_urlhttps://api.deepseek.com仅 B
--responses_api_stream开流式回复
--chat_size10保留最近轮数，省上下文
--tts / --qwen3_tts_*0.6B + Vivian + chinese出声模型、音色、语言、风格 instruct
--devicecudaNVIDIA GPU
--no_smart_turn默认带上有此参数 = 关闭 Smart Turn
PYTORCH_CUDA_ALLOC_CONFexpandable_segments:True环境变量，减轻显存碎片
DEEPSEEK_API_KEY从 dsh 凭据读取仅 B；勿写入仓库

Gateway 五字段：Provider / URL 由本地模式自动填写；模型与音色留空（由上表管理）。
